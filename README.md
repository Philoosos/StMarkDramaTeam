# فريق مارمرقس للدراما | حجز التذاكر

الموقع العربي المحلي لفريق مارمرقس للدراما. يجمع الموقع العام والأرشيف التاريخي، مع نظام التذاكر قيد البناء على مراحل. الأرشيف التاريخي معلوماتي ولا يضيف عروضًا متعددة قابلة للحجز.

## التقنية

- Next.js مع App Router وTypeScript للواجهة وخدمات الخادم.
- PostgreSQL كقاعدة بيانات، مع Prisma ORM لتعريف البيانات وإدارة تغييرات قاعدة البيانات.
- اتجاه RTL واللغة العربية معرفان على مستوى الصفحة، والتصميم يتكيف مع الهاتف والكمبيوتر.
- لا يعتمد المشروع على مسارات ملفات خاصة بهذا الكمبيوتر أو خطوط وخدمات خارجية.
- يستخدم الشعار الأصلي المرفق ولا يعتمد على خطوط أو صور مستضافة خارجيًا.

## متطلبات التشغيل

- Node.js إصدار 20.19 أو أحدث مع npm. الصفحات العامة تعمل دون قاعدة بيانات؛ تسجيل الموظفين ولوحاتهما يتطلبان قاعدة المشروع عبر Docker Desktop.
- Git مطلوب فقط عند استنساخ المشروع أو حفظ نسخة احتياطية على GitHub.
- PostgreSQL مطلوب عند بدء استخدام قاعدة البيانات. يمكن أن يكون محليًا أو مستضافًا سحابيًا؛ لم يتم اختيار مزود أو الاتصال به.

## استئناف العمل على كمبيوتر آخر

1. انقل مجلد المشروع كاملًا أو استنسخه من مستودع خاص بعد إنشائه. احتفظ بمجلد `Markramus-assets-reference`.
2. جهّز Node.js (20.19 أو أحدث) مع npm وDocker Desktop على الكمبيوتر الجديد.
3. شغّل Docker Desktop ثم انقر مرتين على `START-LOCAL.bat`. سينشئ `.env` ومفتاحًا محليًا إذا لزم، ينتظر جاهزية قاعدة المشروع على المنفذ 5433، يثبت الاعتماديات الناقصة، يطبق الترحيلات، ثم يشغل الموقع.
4. لإيقاف الموقع وقاعدة المشروع مع الاحتفاظ ببيانات Docker، انقر مرتين على `STOP-LOCAL.bat`.

لا يلزم أن يبقى الكمبيوتر القديم قيد التشغيل. الشيفرة والإعدادات والأصول المرجعية موجودة داخل مجلد المشروع. مخطط قاعدة البيانات وثلاثة ملفات ترحيل جاهزة لكنها غير مطبقة. خدمة PostgreSQL المحلية العاملة تابعة لبرنامج HikCentral وليست قاعدة المشروع؛ لم يتم تسجيل الدخول إليها أو إجراء أي تغييرات عليها. لا توجد خدمة مدفوعة أو عملية نشر.

## الأوامر

| الأمر | الاستخدام |
| --- | --- |
| `npm run dev` | تشغيل الموقع للتطوير |
| `npm run build` | إنشاء نسخة إنتاج محلية |
| `npm start` | تشغيل نسخة الإنتاج بعد البناء |
| `npm run lint` | فحص قواعد ESLint |
| `npm run db:generate` | توليد Prisma Client من المخطط |
| `npm run db:validate` | التحقق من صحة مخطط Prisma |
| `npm run db:migrate` | إنشاء/تطبيق ترحيل قاعدة بيانات أثناء التطوير |
| `npm run db:deploy` | تطبيق ملفات الترحيل بعد التحقق من جاهزية قاعدة المشروع |

## Git ونسخة GitHub الاحتياطية

المستودع المحلي مهيأ بفرع `main` وفارغ دون commit أو remote. بعد مراجعة الملفات يمكن إضافة أول commit:

```bash
git add .
git commit -m "Set up Arabic theatre ticketing foundation"
```

تم تهيئة مستودع Git محلي فارغ بفرع `main` دون إضافة ملفات أو إنشاء remote. لإنشاء نسخة GitHub، أنشئ مستودعًا خاصًا ثم اتبع أوامر GitHub لإضافة عنوانه ودفع الفرع. لم تُرفع ملفات إلى الإنترنت.

قبل كل رفع، تأكد أن `.env` غير مضاف. ملف `.gitignore` يستثنيه تلقائيًا. ارفع `.env.example` فقط، ولا تضع فيه بيانات دخول فعلية.

## حالة التنفيذ الحالية

تم تنفيذ الصفحة الرئيسية، وصفحة «عن الفريق»، وفهرس أرشيف العروض وصفحات التفاصيل لكل سجل وارد في بروشور الفريق. استخدمت صفحات البروشور الخمس المضمنة في HTML لفهم محتواها، ونُقلت معلومات التاريخ والطاقم والاعتمادات إلى بيانات محلية قابلة للتعديل برمجيًا. لم يبدأ بعد نظام إدارة المحتوى.

شغّلت الموقع محليًا عبر Next.js الموجود داخل المشروع. اجتاز TypeScript وESLint ومخطط Prisma التحقق، واستجابت الصفحات والخط والشعار محليًا برمز 200. اجتاز production build في مجلد منفصل عن خادم التطوير. سكريبت Windows اجتاز فحص الصياغة فقط، ولم يُشغّل end-to-end لأن Docker غير متاح. npm غير موجود في PATH.

دليل التسليم المنظم للمطور موجود في [`docs/developer-handoff/README.md`](docs/developer-handoff/README.md)، ويشرح البنية الحالية والنواقص وطريقة الاستئناف على كمبيوتر آخر.

## متطلبات المشروع المؤجلة

- الصفحة العامة تعرض «المحلج» كتجهيز تجريبي وتوضح أن الحجز غير متاح حتى اعتماد المواعيد ومخزون المقاعد. يمكن لـAdmin إنشاء مسودة مستقلة في قاعدة البيانات.
- صور مخططي Hall وBalcony معتمدة كمراجع بصرية من المالك. لم أعثر على قائمة مقاعد canonical منفصلة قابلة للاستيراد؛ يلزم مطابقة كل كود وموضع وتصنيف قبل إنشاء خريطة بيع تفاعلية.
- مخطط قاعدة البيانات وثلاثة ملفات ترحيل موجودة لكنها غير مطبقة؛ توجد الآن شاشات وكود مصادقة وحسابات موظفين ومسارات لوحة حسب الدور، لكنها لم تُختبر على قاعدة مشروع فعالة. لم يبدأ بعد الحجز الفعلي والدفع وإصدار QR والمسح. لا يوجد ربط دفع أو InstaPay أو رسائل أو خدمات خارجية.
- جمع مستندات الهوية الحساسة يظل معطلًا حتى استكمال مراجعة قانونية وخصوصية مؤهلة في مصر.

## حالة هذه المرحلة

الموجود حاليًا هو الأساس العام والهوية والأرشيف، ومخطط بيانات أولي وMigration لم يطبقا بعد، وتجهيزات التشغيل المحلي. تنفيذ التطبيق المحلي مصرح به وفق Master Build Prompt؛ أما النشر أو شراء الخدمات أو إنشاء حسابات خارجية أو توصيل مزودي دفع/رسائل حقيقيين فغير مصرح به.
